## Authored this round

**New rule — `dont-waste-discard-energy`** (general Strategy, deck-agnostic; weight −40, effective
−42.54 after the fit; `status="testing"`).

- **What:** penalise attaching a **discard-at-end-of-turn Energy** (Function Tag `discard_eot`, now
  on Ignition Energy via `function_overrides.json`) when it would be wasted —
  `when = option_type==ATTACH and "discard_eot" in tags and (target is benched OR first turn going
  first OR a reusable Basic is in hand and the target isn't the win-condition)`.
- **Why:** Ignition discards each turn, so it's only worth it if the holder attacks **this** turn. 5
  corrections flagged spending it on Cinderace/Staryu when a Basic was available or it couldn't
  attack. A **route-H** fix (no re-weighting expressed it).
- **Universal by design:** keys on the `discard_eot` tag + universal `Board`/`Context` signals
  (`reusable_energy_in_hand`, `attach_target_area`, `attach_target_roles`), so any future deck running
  Ignition (or another discard-EOT Energy) inherits it — it lives in `common/general_strategy.py`.
- **Preserves the good line:** with **no** Basic in hand, `Ignition → active Cinderace` is *not*
  penalised (scores 40), so the Turbo Flare line (attack to search 3 Basic Energy onto the Bench)
  still fires. Onto the win-condition it's never penalised (its bulk CCC is the payoff).
- **Verifier/retest:** correct now outranks chosen at ep 81903490 f49 / f27 and ep 81904451 f6
  (`Attach Ignition → Basic` flips); no regressions. (f5/f50 are Ignition-vs-Play turn-1/fetch cases —
  the waste is penalised, but their full fix is the sequencing cluster below.)
- **Side effect (the W-vs-H point):** authoring this rule keeps `accel-into-main` healthy (30 → 27.46)
  instead of the gutting (→ ~2) the tuner attempted before the rule existed.
