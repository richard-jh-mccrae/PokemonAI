Machine Learning — One-Page Formula Reference

Companion to A Systems Engineer's Introduction to Machine Learning. Each formula: what it is, and the one-line reason we use it. Symbols: w=weights, φ=features, m=margin, η=learning rate, λ=regularisation, τ=hinge target.

The decision — Ch 1–3

Score(o) = w·φ(o) + tactical(o) = Σi wiφi(o) + tactical

A linear model: a weighted sum of (mostly binary) features. Legible, convex to fit, cheap.

chosen = argmaxo Score(o)

The decision rule. Only score differences matter; a knockout's huge tactical is a hard override.

Learning to rank — Ch 4

Δi = firedi(k) − firedi(c) ∈ {−1,0,+1}

margin m = Σi wiΔi + Δtactical   (satisfied ⇔ m>0)

A correction "k should beat c" becomes one linear inequality. Some Δ≠0 → route W (reweight). All Δ=0 → route H (blind; needs a new feature).

Loss functions — Ch 5

hinge: L = max(0, τ − m)  SVM

Zero once satisfied past τ; convex surrogate for the intractable 0/1 loss. Only "support vectors" (m<τ) drive the fit.

log-loss: L = −[y·ln p + (1−y)·ln(1−p)]

For probabilities; savagely punishes confident-wrong. Squared loss (y−ŷ)² is for regression.

Fitting the weights — Ch 6

J(w) = Σ max(0, τ−m) + (λ/2)Σ(wi−wiseed)²

Fit corrections and stay near the expert seed (L2 = Gaussian prior). λ = conservatism knob.

perceptron: wi ← wi + ηΔi ; then wi ← wi − ηλ(wi−wiseed)

stubborn fixed point: w* = wseed + p/λ

Sub-gradient descent. Pocket: return best-J iterate (data is non-separable). Gate: ship only if it satisfies more.

Probability out — Ch 7

σ(z) = 1 / (1 + e−z) ,   z = w·φ + b

Logistic regression: squash a linear score into (0,1). σ(0)=0.5; σ(−z)=1−σ(z).

coin-flip floor = −ln(0.5) = ln 2 ≈ 0.693

Beat it on held-out log-loss ⇒ real signal. Standardise features first: (φ−μ)/s.

Deck odds & EV — Ch 8

C(n,k) = n! / (k!(n−k)!)

P(deck holds ≥1) = 1 − C(K,u)/C(H,u)

Hypergeometric (draw without replacement). u=unseen copies, K=hidden prizes, H=deck+K. Exact — no sampling.

EV = Σ P(outcome)·value(outcome)

Fair price of a gamble. Gamble iff EV>safe — not "P>50%". Break-even = EV equality.

Search — Ch 9

minimax: MAX=max(children), MIN=min(children)

expectimax: chance node = Σ P·value(child)

tree size ≈ bd  (branching b, depth d)

Exponential ⇒ depth-limited. Sound "lethal" solver proves a win (never over-claims). not AlphaZero — no data/compute/legibility for MCTS+net.

Evaluation — Ch 10

SE = √( p̂(1−p̂)/N ) ,   95% CI ≈ p̂ ± 1.96·SE

Width shrinks like 1/√N (4× games → half the width). If the CI crosses 50%, the effect is not shown.

Gate, not optimiser. Held-out + independent A/B beat "it fits my corpus" (Goodhart). Paired-delta cancels the raw matchup. Parked-OFF with evidence is a valid result.

The compass — Ch 11 transfer

Pick the method by the constraints, not the hype:

1. How much data?   2. Compute/runtime budget?

3. Feedback density?   4. Must it be legible?

5. Do I already know the structure?

Little data + tight runtime + legibility + known structure ⇒ linear model + exact math + a thin learned seam. Bias–variance: simple = high bias/low variance (wins on little data).
