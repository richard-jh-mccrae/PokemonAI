The Fail-Direction Rule

Which way to round an uncertain value feature — the one-page version.
The rule

Round an uncertain estimate toward the mistake you can afford; away from the one that loses a game. Both self- and opponent-side features share one goal — be pessimistic about your own safety — which forces opposite arithmetic.

The decision procedure

  1. Name the two possible errors: a false “yes” and a false “no”.
  2. Ask which one, if committed, loses a game (not just a nudge). That is the catastrophic error.
  3. Make the estimate structurally unable to commit the catastrophic one — round the other way.
  4. When you cannot bound the uncertainty at all, credit the safe extreme (0 reach for me / full reach for them).

Glossary of the rule

Value feature — a number computed about a position that feeds the decision (a φ).
Fail-closed — when unsure, refuse to claim more than you can prove (self-capability).
Fail-open — when unsure, assume the alarming reading is real (opponent threat).
Fail direction — which way a feature rounds under uncertainty; set by the asymmetric cost of its two errors, not by nearness to the truth.
readiness_p — the EV softening of a fail-closed boolean: P(the enabler lands), 1.0 if certain, else hypergeometric; still credits 0 when unbounded.
